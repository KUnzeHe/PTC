## 当前入口与验收

```powershell
python "04-仿真\propagation_matrix"
python "04-仿真\clean_ptc_k_gap.py"
python "04-仿真\clean_ptc_ssh_equivalence.py"
```

第一个入口比较单层解析传播矩阵与独立 Maxwell ODE 轨迹，并自动检查：

- $\det P_j=1$；
- $P_j^{(-)}P_j^{(+)}=I$；
- 均匀介质的分段合并性质；
- 归一化状态的最大 ODE 相对误差。

当前示例四项检查全部通过，最大 ODE 相对误差约为 $1.6\times10^{-11}$；验证图保存为 `propagation_matrix_validation.png`。

第二个入口默认使用 Yang Figure 1(c) 的 $n_1=4,n_2=2,\bar t=1\,\mathrm{fs}$，从周期矩阵 $M=P_2P_1$ 计算 Floquet 色散，输出允许带、$k$-gap 和 $\cos(\Omega T)=\mathrm{Tr}(M)/2$ 判据图，结果保存为 `clean_ptc_k_gap.png`。该脚本用于结果复现，不承担独立验证功能。

第三个入口将 TMM 数据映射到 $(q,\lambda)$ 坐标后与 SSH 能带叠加，逐点验证迹恒等式，并比较 $n_1>n_2$ 与 $n_1<n_2$ 的 winding 路径和开边界谱。所有必要结果统一保存在 `clean_ptc_ssh_equivalence.png` 中，数值误差、手征对称、谱成对、拓扑标签和边界态仍由脚本自动检查，但不单独作图。
